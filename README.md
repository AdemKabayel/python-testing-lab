# python-testing-lab

A running collection of Python testing practice - starting with `pytest`
fundamentals and growing as I work through more tutorials and learnings.

## Contents

- `tests/` — pytest exercises,

More topics will be added over time as separate sections below.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Running tests

```bash
pytest test_main.py
```
