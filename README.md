# python-testing-lab

A running collection of Python testing practice — starting with `pytest`
fundamentals and growing as I work through more tutorials and learnings.

## Contents

- `tests/` — pytest exercises, following along with [Please Learn How To Write Tests in Python… • Pytest Tutorial](https://www.youtube.com/watch?v=EgpLj86ZHFQ)

More topics/tutorials will be added over time as separate sections below.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Running tests

```bash
pytest
```
